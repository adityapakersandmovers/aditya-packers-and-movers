# Google Search Console Verification

## How to verify ownership in GSC

1. Go to https://search.google.com/search-console
2. Add property: https://www.adityapackersandmoversrjy.in/
3. Choose "HTML file" verification method
4. Download the google*.html file Google provides
5. Place it in the /public/ folder of this project
6. Commit and push — Vercel will serve it at the root
7. Click Verify in GSC

## After verification

1. Submit sitemap: https://www.adityapackersandmoversrjy.in/sitemap.xml
2. Use URL Inspection on: https://www.adityapackersandmoversrjy.in/
3. Request indexing
4. Monitor Coverage report

Place a 1200x630px image named `og-image.jpg` in /public/
This will be used for social sharing previews.
